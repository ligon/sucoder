* Completed phase

The human reported two mirror-image annoyances: a local =sucoder collaborate= started outside tmux is hard to manage, and a remote =sucoder -T savio collaborate= started inside tmux nests two tmuxes.
This session added an early =$TMUX= check to =collaborate=, =agents-run= and =attach=, before any ssh or allocation, on branch =feat/tmux-nesting-check= cut from =ligon/main= at =cd1eb8f=.

* What changed

- [[file:../sucoder/tmux_env.py][sucoder/tmux_env.py]] (new) :: =detect()= reads =$TMUX= and asks the outer server for its session name and prefix; argv builders for =new-session=, =attach-session= and =switch-client=; the two warning texts.
  Probes drop =$TMUX= from their environment so they always address the default server, and targets carry the ~=~ exact-match prefix.
- =sucoder/cli.py:2227= =_tmux_launch_preamble= :: called first in =agents-run= (=cli.py:2425=) and =collaborate= (=cli.py:2560=).
  Remote target inside tmux: one stderr note, then continue.

  An existing session is attached rather than duplicated.
  Non-TTY, =TERM=dumb=, no tmux, or =--no-tmux= (new flag on both commands) leave the launch in place with a one-line note; =--dry-run= describes the re-exec and stays.

* Important choices

- The local launch is re-executed inside tmux rather than wrapping the agent command in tmux: the session then belongs to the human's own tmux server, and the launch itself (=sudo=, TTY, post-session hooks) is untouched.
- The nested remote case is structural: the remote tmux is what survives disconnects and what =message=, =peek= and =renew= address.
  The note names the outer session and prefix, and says =C-b C-b d= detaches the remote while =C-b d= detaches the local one; the README mentions the =key-table off= binding for people who nest often.
- A bare =tmux has-session -t sucoder-Foo= is a prefix match and answers for =sucoder-FooBar= (checked on tmux 3.5a), hence the ~=~ prefix everywhere.
- =switch-client= needs a current client, so it is only used when =detect()= says the outer tmux is the default server.
