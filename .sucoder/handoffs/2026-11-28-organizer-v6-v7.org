* How to run

#+begin_src sh
sucoder() { PYTHONPATH=/home/coder/mirrors/SuCoder /opt/sucoder/bin/python -c 'from sucoder.cli import app; app()' \
                --config /home/coder/.sucoder/config.yaml "$@"; }
sucoder dream organize plan SuCoder --area ID --title TITLE --group GROUP --summary TEXT --term TERM ...
sucoder dream organize run SuCoder --plan PLAN --harness codex --model gpt-6.2-astra --effort high \
     --cross-harness codex --cross-model gpt-6-astra --cross-effort high --same-family-review
#+end_src

=--title=, =--group= and =--summary= are needed only the first time an area is organized.
Without =--term=, the terms come from the area's id, title and summary; for =observation= that adds broad words such as =session= and =status= and delivers 79 items instead of 55.
A failed run is retried with =--attempt 2= on the same plan.
