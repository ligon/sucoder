* 3. Definitions and conventions

V1 validates explicit citation ranges and exact quotes.
V2-v6 resolve an admitted-unit/quote pair at one unique source position, with v4-v6 restricting the search to delivered windows; the coordinator computes offsets.
V7 selects a namespaced handle for one exact delivered span; Python resolves its quote and offsets without a uniqueness search.
Every changed non-index anchor currently needs a reference unless covered by a verified derived editorial action.
V6 and v7 briefs explicitly include Talk in changed-anchor coverage; E6's v5 wording was less explicit.
The implemented production contract at this baseline is =source-grounded-wiki-v7=, layered over v6 diagnostics and v5 editorial actions; earlier versions remain frozen.
Raw completion, mechanical acceptance, independent acceptance and memory publication are distinct states.
Wallet =completed= records native delivery, not an accepted revision; the current local =max_repairs= loop does not provide a durable logical-round state machine.
An unreviewed draft checkpoint may save work but cannot establish accepted progress or source coverage for a future job.
Cache reads are observations, not evidence of comparative savings; missing native usage remains unknown.

- Extend :: Existing typed editorial materialization and reference resolution for coordinator-owned structure and evidence handles.

- New :: Durable logical repair-round identity/outcomes, separate from charged native attempts and authenticated context-lookup continuations.
- Extend :: Frozen role policies/profile identities for supported effort/output controls and explicit review reserves.
- Extend :: The existing reviewer candidate hook with bounded, coordinator-generated before/after page differences, binding every changed output including index and generated pages.
- New :: A v8 per-page review matrix for support, scope, time, causality, outcomes, attribution, preservation and summary; the existing verdict/findings schema cannot require these checks.

  Handles remain optional exact-source pointers, not semantic proof; live calibration is required before claiming this catches E9.
- Defer :: Direct APIs, unrestricted tools, automatic paid retries, wholesale rendering rewrites and new discovery infrastructure until controlled measurements justify them.
