* 3. Definitions and conventions

An exact citation currently names an admitted unit and a quote occurring at exactly one absolute position in its delivered windows; the coordinator computes offsets.
Every changed non-index anchor currently needs a reference unless covered by a verified derived editorial action.
The author brief says explanatory sections; that wording does not fully describe the changed-anchor check applied to Talk in E6.
The current production editor contract is =source-grounded-wiki-v5=, layered over the earlier v1-v4 contracts; do not allocate an already-used version.
Raw completion, mechanical acceptance, independent acceptance and memory publication are distinct states.
An unreviewed draft checkpoint may save work but cannot establish accepted progress or source coverage for a future job.
Cache reads are observations, not evidence of comparative savings; missing native usage remains unknown.

* 4. Invariants

Keep explanatory prose and synthesis, uncertainty, attribution, human decisions and bounded open-ended discovery.
Keep source admission, private evidence, tool prohibition, immutable request/trace bindings, independent semantic review and compare-and-swap publication.
Do not turn Talk, unanchored prose or a model-supplied section type into a route for unsupported factual claims.
Do not guess among ambiguous source positions, edit unseen pages from search snippets or promote model summaries to evidence.
Keep old contract/policy/schema dispatch and original replay semantics; E6 must remain incomplete under its frozen contract.
Never rewrite an old raw reply, failed reservation, manifest or result to make it acceptable under a new contract.
Keep global call/time charges across explicit phase retries; started unknown work is never silently reissued.
Keep dynamic evidence handles in bound request data, not volatile tool/schema enums in the cache prefix.
Certify new policy/schema/control combinations before stable production use; keep unsupported hard token/currency requests rejected before provider work.

* 5. Reuse decisions

- Reuse :: Native Org inventory, existing citation checks, bounded context, submission wrappers, wallet, accepted-progress proofs and sole publisher.
- Extend :: Mechanical validation into dependent read-only passes with bounded, located diagnostics; the present first-error exception hides independent defects.
- Extend :: Existing typed editorial materialization and reference resolution for coordinator-owned structure and evidence handles.
- New :: A versioned unreviewed-draft/phase checkpoint protocol; accepted receipt reuse cannot represent an unaccepted proposal safely.
- Extend :: Repair into hash-bound typed patches, using the fully delivered draft and existing private materialization boundary.
- Extend :: Frozen role policies/profile identities for supported effort/output controls and explicit review reserves.
- Defer :: Direct APIs, unrestricted tools, automatic paid retries, wholesale rendering rewrites and new discovery infrastructure until controlled measurements justify them.

* 6. Decisions for plan review

The first slice retains strict changed-anchor coverage and makes the model policy explicit, including Talk; typed citation-free containers are a later semantic design decision.
A proposed 180-second review reserve is a pilot starting point, not a measured reviewer requirement or completion guarantee.
Native effort/output mappings must be verified for the selected installed builds before selecting defaults; no vendor capability is assumed here.
Controlled live allowances and private evidence selection require explicit authorization after offline preparation; this plan grants neither.
