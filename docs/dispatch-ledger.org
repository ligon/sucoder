* 3. Definitions and conventions

A dispatch is a bounded Slurm job with one independent headless worker and a unique dispatch ID.
The source is an immutable, committed Git object available from a shared repository; the coordinator's node-local checkout is not a cross-node source.
The source repository is read-only to dispatch; worker commits and dirty snapshots are durable in a separate private bare result repository.
The worker uses a full clone, not a Git worktree with its index on shared storage.
Live agent state belongs on the receiving node; durable snapshots and results belong on shared storage.
Codex and Claude command adapters are explicit; an unknown harness must refuse rather than inherit interactive flags.
Headless means no terminal, tmux, app-server attachment or interactive approval prompt.

* 4. Invariants

Never reuse an inherited coordinator =SUCODER_LOCAL_ROOT=, runtime identity or remote-control receipt.
Resolve =SLURM_JOB_ID= inside the receiving allocation and verify its local filesystem.
Do not hydrate partial source repositories or mutate their refs, index, checkout or configuration.
Pin and recheck the requested source commit; never guess from the source's checked-out branch.
Private prompts, credentials, logs and state require private directories and files; secrets never belong in command arguments or diagnostics.
No success claim without an explicit worker result; scheduler failure and absent/unreadable result remain distinct.
Process exit and state preservation are separate facts; issue 70 can still produce a crash generation after a clean Codex exit.
Do not copy live SQLite databases and sidecars as ordinary files.
Preserve current interactive launch, synchronization and recovery behavior.
