* Defects and fixes

- Finish on the last call (=04d38ed=, =531df2b=) :: Run 1 spent its eighth and last discovery call on a read, giving the rationale "Use the final discovery read", as though a finish turn would follow.
  =finish= counts as a discovery call, and the brief never said so.
  Both briefs now say so, and the last call offers only =finish= in experience and project mode alike.
  Project mode had been left frozen to protect replay, but bare =dream= exists only on unmerged branches and no project job has ever been stored.
- Failures (=531df2b=) :: Run 2 finished with a sound two-source selection, but listed two unverified caveats as =failures=, and any listed failure rejects the job.
  P6's grader hit the same ambiguity.
  =failures= now means only that the turn's request could not be carried out.
- Invisible memory (=531df2b=) :: The experience brief asked the explorer to verify "the existing memory", which its inventory does not contain.
  It now says that the author and reviewer receive the memory with the selection and decide novelty.
- Topic names (=4535965=) :: Run 3's finish gave a phrase as its topic, and the simple-name check refused it on the last call, losing the selection.
  Run 2's topic would have failed the same way.
  A phrase now becomes a lowercase hyphenated name.
- Line ends (=4535965=) :: Runs 2 and 3 lost three of their sixteen calls to reads such as lines 1-220 of a 109-line file.
  An end past the last line now reads, or selects, through the end of the file.
- Long records (=c0d8ddd=) :: Session =fbcd2c8d= holds a 143 KB attachment record from raw offset 274704 to 417929.
  Run 4 lost two calls on reads ending inside it, each refused as an empty window, with no way to learn where the record ended.
  A window now always holds its first record, and =range_too_large= reports the offset to skip to.
- Earlier source links (=9755ae1=) :: Run 5 was the first to admit a rendered session window.
  Its author listed a new topic in the index, but the index still linked =docs/reply-transcripts-evidence.org= and =sucoder/reply_probe.py=, admitted by P2 and not by this run.
  The validator refused the edited index, before and after repair.
  An in-place memory branch keeps earlier generations' links, so every dream that edited such a page would have been refused.
  A source link the same page already carried is now accepted; a new unadmitted link is still refused, and so is a carried link moved to another page or repeated.
  =validate_proposal= has CRITICAL impact (358 symbols, 79 processes), and the human approved the change.

- Email addresses (=09b2863=) :: The running session's render contained the human's email address.
  It would become eligible for a dream after 30 quiet minutes, and the redaction patterns covered credentials only.
  Every email-shaped string is now redacted, except SSH remote specs (=git@host:...=).
  Python decorators in escaped commands and grep output are not mistaken for addresses.
  No render of this mirror's three sessions now contains the private address, and the window that run 6 published renders unchanged.
  =redact= has CRITICAL impact, and the human approved the change.
  The private address never reached the provider: no stored lookup, evidence file or assignment of the six jobs contains it.
  The only address in them is =noreply@anthropic.com=, from commit trailers in discovery reads.

Each fix has targeted tests.
The new jobs make three of the old ones replay differently: jobs 1-3 because the briefs changed, and job 4 because its two refused lookups would now succeed.
