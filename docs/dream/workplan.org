* Delegate the knowledge work to the agent
:PROPERTIES:
:CUSTOM_ID: delegation
:END:

Give the dreaming agent a purpose, admitted evidence, relevant prior wiki, bounded read/search access and an isolated candidate workspace.
Let it decide what matters, investigate relationships, write explanations, revise wrong notes, merge duplicates, propose removal of obsolete material and organize topics and links.
It may ask for more evidence or identify uncertainty instead of manufacturing an answer.
Useful plans, successful procedures, failures and tested rules are all eligible; no fixed rule such as recording only failures determines salience.

The coordinator retains source admission, privacy, filesystem authority, accounting, complete selected-evidence coverage, mechanical validation, receipts and the sole right to publish git objects/refs.
An independent checking pass assesses support, missing qualifications and unresolved conflicts; successful schema validation cannot prove semantic correctness.
Human decisions and contributions remain attributed, and an agent inference cannot silently supersede a recorded human decision.
Source text cannot grant tools or change the task's authority.

Replace the current titles-and-claim-IDs consolidator with an author/editor that can produce explanatory Org pages and a source-bound change manifest.
Schemas should constrain source identities, edits and dispositions while allowing the agent to compose prose and select what deserves publication.
Do not require every extracted claim to appear verbatim or survive forever; record material omissions, merges and replacements with their reasons.
Complete evidence delivery and selective publication are different requirements.

For the first correction/synthesis slice, a small complete evidence bundle can be delivered inline through the existing transports.
As context grows, add bounded coordinator-served read/search requests over frozen sources and prior pages, or native file tools only after their capabilities are verified.
This gives the agent useful investigative choices without unrestricted access to the real repository, home, network tools or git metadata.
Use disjoint analyst outputs when delegation helps, then one editorial owner and publisher; a fixed number of agents is not a success criterion.
