* Definition of done

- Normal native wiki and notes runs have a persisted job budget by default, using the plan's existing elapsed/invocation ceilings.
- An explicit private budget directory can share one allowance across several plans; a new attempt never silently resets it.
- Every native call is reserved durably before invocation, including failed/unknown outcomes; concurrent coordinators cannot overspend the same budget.
- Wall-clock and native-call ceilings are enforced with a reserved closeout allowance; model assignments receive frozen, replayable remaining-budget advice.
- Requested hard token or dollar ceilings are rejected before provider work when the selected native adapter cannot guarantee them.
  Observed native usage is aggregated separately, and missing usage/currency remains unknown.
- Exhaustion produces a structured =budget_exhausted= outcome and durable checkpoints; no unchecked candidate is published.
- Read-only budget inspection and cached role/status replay remain available after exhaustion, including saved legacy runs.
- Tests cover shared retries/restarts, explicit shared plans, unknown outcomes, concurrent ownership, clock/deadline drift, closeout, rejected unsupported ceilings and both harness protocols.
- CLI documentation and the configuration example describe the supported settings and limits without inventing a dollar/token guarantee.

* Implementation decisions

Budget settings are execution inputs rather than additions to the frozen source-plan schema.
The default budget lives under the private plan directory; =--budget= names a private shared budget directory when an operator wants a larger job scope.
Budget identity and frozen per-assignment advice bind new run identities while old specifications without budget metadata retain their original reconstruction.
Native role limits count invocations, not hidden HTTP requests.
The existing native adapters do not expose a demonstrated complete token/dollar bound, so this slice advertises hard elapsed/call limits and rejects unsupported hard financial/token settings.
The coordinator retains exact role results, traces and incomplete work privately when review cannot finish.
Review/repair/consolidation may consume the reserved closeout allowance; ordinary author/extractor work stops earlier.
No scheduler, automatic provider fallback, new corpus experiment or alternative Claude account is introduced.
